Python To-Do List Manager

A command-line task management application developed with Python.

Features

- Add new tasks
- Display all tasks
- Mark tasks as completed
- Delete tasks
- Automatically save tasks
- Load saved tasks when restarting the application

Technologies

- Python 3
- JSON
- OS
- Datetime

Data Storage

Tasks are stored locally in a JSON file ("memoire.json"), allowing data to persist between sessions.

How to Run

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project folder.
4. Run:

python main.py

Learning Objectives

This project was developed to practice:

- Python functions and data structures
- Lists and dictionaries
- JSON file handling
- Data persistence
- Exception handling
- Python standard library modules
